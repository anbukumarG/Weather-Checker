🌦️ Weather Checker Web App

A simple and responsive **Weather Checker Web Application** built using **HTML, CSS, and JavaScript**, integrated with a real-time weather API.

This application allows users to search for any city and instantly get accurate weather details such as temperature, humidity, wind speed, and weather conditions along with dynamic icons.

---

Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature display (in °C)
* 💧 Humidity information
* 🌬️ Wind speed details
* 🌥️ Dynamic weather condition icons (Clouds, Rain, Clear, etc.)
* ⚡ Fast and responsive UI
* ❌ Error handling for invalid city names

---

Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Weather API (OpenWeatherMap)

---

 How It Works

1. User enters a city name
2. Application sends a request to the weather API
3. API returns real-time weather data
4. Data is displayed on the UI with corresponding icons
